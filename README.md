# 家庭医疗记录工作台

为家人记录就诊、治疗与体征的本地工具。数据仅存浏览器 localStorage，可导出 JSON / CSV 备份。

## 使用
直接用浏览器打开 index.html 即可，无需服务器。

## 功能
- 家庭成员管理（资料、血型、体重身高 BMI、常用医院）
- 记录类型：看诊预约 / 化疗 / 输血 / CBC血常规 / 就诊 / 住院 / 体征 / 用药 / 报告 / 自定义
- 输血记录「每袋 / 合计 / 袋数」分行展示
- 统计卡片（化疗周期 / 输血袋数 ml / 自定义）
- 趋势图（按记录类型分图、可配置系列）
- Excel(CSV) / JSON 导出、导入备份
- 主题切换

## 部署（GitHub Pages）
push 到 GitHub 后，在仓库 Settings → Pages 选择 main 分支根目录即可获得永久链接。
